# 旅先85択ルーレット

男2人の2026年11月1泊2日旅行向け、旅行先を決める二段階ルーレットです。

## あそびかた

1. [旅行ルーレットを開く]
2. 「全国17エリア」から最初のルーレットを回す
3. 当選したエリアの5候補から2回目を回す
4. 行き先が決定！ 結果を友達に共有できます

対象は全国17エリア×5候補の合計85か所。関東を除き、北海道・沖縄・韓国・台湾も含みます。
海外や移動負担の大きい候補を除外する設定もあります。

[85候補の説明を見る](DESTINATIONS.md)

## GitHub Pages を有効にする（リポジトリの管理者向け）

1. [Settings → Pages]を開く
2. **Build and deployment → Source** を **Deploy from a branch** に設定する
3. **Branch: main / (root)** を選び **Save**
4. 公開されたら友達に送る

静的HTMLだけで動き、アプリのインストール・ログインは必要ありません。

※ 2026年11月17〜19日、東京発、予算5万円までの条件を念頭に候補を掲載していますが、85か所すべての旅行代金をリアルタイム確認・保証したものではありません。
